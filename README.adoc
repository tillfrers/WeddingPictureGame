== WeedingPictureGame

== Disclaimer
This project was built for my own wedding, nothing more. It isn't configurable and plenty of it is hardcoded — it just needs to work.

It's a simple ASP.NET backend with a Svelte frontend. Wedding guests use the site to upload photos per table as part of a photo challenge. At the end of the wedding, an invite link lets guests browse and download all the photos. This ist strictly a private project.
